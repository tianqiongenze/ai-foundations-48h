# 02 架构说明（TOGAF 四域视角）

> 项目：综合项目答辩（档案袋自检）

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 把 12 周积累变成可交付的证据链 |
| 数据架构 | 五层 starter 存在性 → 提纲 → 三问预演 |
| 应用架构 | core 分层定义 + 自检 + 提纲渲染；pipeline 输出交付清单 |
| 技术架构 | Python 3.12 + conda ai48；零依赖；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 分层定义/自检/提纲渲染 | `LAYERS/check()/outline()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
