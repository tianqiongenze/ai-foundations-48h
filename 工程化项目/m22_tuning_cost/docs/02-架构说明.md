# 02 架构说明（TOGAF 四域视角）

> 项目：XGBoost 参数调优与工时账

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 让调参决策有量化依据 |
| 数据架构 | 调参空间 → 两种搜索 → CV 分数 + 耗时 |
| 应用架构 | core 造数/两种搜索/指标；pipeline 输出工时账 |
| 技术架构 | Python 3.12 + conda ai48；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 造数 + 两种搜索 + 指标 | `make_data()/search()/summarize()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
