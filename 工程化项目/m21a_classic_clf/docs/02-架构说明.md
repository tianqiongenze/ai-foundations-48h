# 02 架构说明（TOGAF 四域视角）

> 项目：传统分类：逻辑回归 + 决策树

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 双模型同台对比，用证据说话 |
| 数据架构 | 4 维特征 + 三态标签 → 混淆矩阵 + 漏报账 |
| 应用架构 | core 造数/训练/手写混淆矩阵；pipeline 双模型对比 |
| 技术架构 | Python 3.12 + conda ai48；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 造数/训练/混淆矩阵/漏报 | `make_data()/confusion()/evaluate()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
