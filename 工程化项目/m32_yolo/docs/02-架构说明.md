# 02 架构说明（TOGAF 四域视角）

> 项目：YOLO 实时缺陷检测

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 先手搓检测器再谈深度学习 |
| 数据架构 | 合成 64×64 图 → 滑窗分数图 → 框+IoU+FPS |
| 应用架构 | core 造图/滑窗/检测/IoU/FPS；pipeline 输出取舍表 |
| 技术架构 | Python 3.12 + conda ai48；numpy/Pillow；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 造图/滑窗/检测/IoU/FPS | `make_scene()/score_map()/detect()/iou()/fps()` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置
