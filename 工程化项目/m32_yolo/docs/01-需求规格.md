# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：YOLO 实时缺陷检测（05-AI应用基础48课时版 · W16 第15次课）

## 1. 范围
滑窗+阈值+IoU+FPS 手搓检测器，并做 win 尺寸取舍实验；理解 YOLO'锚框/步长调参'的同一问题。

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-01 | 作为学员，我想理解检测器原理 | 滑窗+阈值复现 |
| US-02 | 作为工程师，我想量化取舍 | win-IoU-FPS 表 |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 滑窗分数图 | 窗口均值 |
| F-02 | 阈值检测 | 最大点+阈值 |
| F-03 | IoU 评估 | ≥0.5 合格 |
| F-04 | FPS 基准 | 200 次计时 |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子，重复运行结果一致 | 二次运行 diff |
| NF-2 | 可移植 | 仅标准库 + numpy、Pillow；任意 conda 环境可跑 | 换机运行 |
| NF-3 | 可配置 | 全部阈值/清单在 config/rules.yaml | 改配置不改代码 |
| NF-4 | 可测试 | pytest 用例 ≥ 6，覆盖正常/边界/异常 | `pytest -q` |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet]`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/*.json`

## 7. 追踪性
本规格 ↔ docs/03 设计说明 ↔ tests/ ↔ 工单任务书 三层一一对应。
