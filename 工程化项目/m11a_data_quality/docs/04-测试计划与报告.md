# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：数据清洗与质量评估（工单 M1-1a）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，`core` 纯函数 | 覆盖正常/边界/异常三档 |
| 门禁测试 | pytest，`test_tiers.py` 端到端跑流水线后读 `result.json` | 工单 D/C/B/A 四档数值线写成断言 |
| 配置测试 | pytest，`test_config.py` 逐键覆盖重跑 | 证明 `rules.yaml` 真被读取（非装饰） |
| 集成测试 | `pipeline.run` → `output/` 七件产物 | 输入→输出链路正确 |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |

## 4. 缺陷记录
| 编号 | 描述 | 处置 |
|---|---|---|
| BUG-01 | 旧实现用 `dropna` 把 300 行删到 275 行来"消灭缺失"，违反 D 档"行数不变" | 改为逐列四策略填充，缺失阶段零删行；台账落 `audit_log.csv` |
| BUG-02 | 旧质量分公式 `(n/(n+bad))²` 与工单 B05「完整×准确×一致加权」不符 | 改 `core.quality(comp,acc,uniq,w)`，权重外置且和必须为 1 |
| BUG-03 | 异常识别只有固定上下界，无 IQR/3σ | `anomaly_profile` 三把尺并扫，输出各自边界与命中数 |
| BUG-04 | 无重复检测（`duplicated()` 缺失） | 新增重复清单 + 按清单行号处置 |
| BUG-05 | 填充实验若把注入毛刺当考卷，两法误差都被 135℃ 拉平、改善仅剩 1.5% | `value_valid_mask` 先过三把尺再出题，改善回到 74.79% |
