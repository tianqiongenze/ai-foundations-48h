# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：数据清洗与质量评估（05-AI应用基础48课时版 · W07 第1次课）
> 文档版本：v1.0　编制日期：2026-10-14　密级：教学内部

## 1. 范围
合成带脏泵站日志，实现缺失/超限/负值三类处理与质量评分，并做纯Python与Pandas双解互验（同口径同结果）。

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-01 | 作为分析员，我希望两解结果一致 | 越量程标记行数与规则完全相同 |
| US-02 | 作为值班师傅，我希望"行数不变"地消灭温度缺失 | 温度缺失率归零且缺失阶段零删行 |
| US-03 | 作为组长，我要一张能汇报的质量分 | 完整率×准确率×一致率加权，前后各评一次 |
| US-04 | 作为答辩评委，我要"预测填充优于均值"的数字 | 同一留出实验的 MAE/RMSE 对比 |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 三清单体检 | 缺失(`isna().sum`)/异常(物理量程+3σ+IQR)/重复(`duplicated`) |
| F-02 | 缺失填充四策略 | 温度时序插值、振动中位数、电流 ffill、压力整列策略（行数不变） |
| F-03 | 异常识别两把尺 | 3σ 与 IQR 并集 + 物理量程硬闸；只标记不删行 |
| F-04 | 重复处理 | 按重复清单行号删除，清单↔处置可追溯 |
| F-05 | 质量分 | `quality = w1·完整率 + w2·准确率 + w3·一致率`，权重外置 |
| F-06 | 预测 vs 均值填充实验 | OLS（日内周期+振动+电流+机号）留出对比，防泄漏 |
| F-07 | 双解互验 | 纯 Python 逐行 vs Pandas 掩码，同规则同结果 |
| F-08 | 留痕落盘 | 三清单 CSV + audit_log.csv + cleaned.csv + result.json |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子，重复运行结果一致 | `test_config.py::test_run_is_reproducible` |
| NF-2 | 可移植 | 仅标准库 + numpy、pandas（预测填充用 `np.linalg.lstsq`，不引 sklearn） | 换机运行 |
| NF-3 | 可配置 | seed/unit/topk/warn/danger/权重/目标线全在 config/rules.yaml | `test_config.py::test_*_is_read` |
| NF-4 | 可测试 | pytest 用例 ≥ 30，覆盖正常/边界/异常 + 四档门禁 | `pytest -q` |
| NF-5 | 可入口 | `run.py` 与 `pip install -e .` 后的 `m11a_data_quality` 命令同源（`cli:main`） | `test_cli.py` 约定 |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet]`；等价 `m11a_data_quality`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/result.json`、`output/missing_list.csv`、
  `output/anomaly_list.csv`、`output/duplicate_list.csv`、`output/audit_log.csv`、
  `output/cleaned.csv`
